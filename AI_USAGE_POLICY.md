## Restriction on AI Training Use

This repository and its contents — including source code, documentation,
configuration files, and all other artifacts — **may not** be used to train,
fine-tune, evaluate, or otherwise develop machine learning or artificial
intelligence models without the **explicit written permission** of the
repository maintainer.

## Permitted Uses

- Personal study and educational purposes
- Building applications that use this project as a dependency under Apache-2.0
- Contributing improvements back under the project's open-source license

## Prohibited Uses

- Scraping or extracting this repository's content as a training dataset
- Including this repository's content in AI/ML training corpora without permission
- Automated bulk extraction for model pre-training or fine-tuning
